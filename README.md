# ShareWay UTP

**AI-powered shared transport planner for UTP student travel**
TEB2023 Artificial Intelligence · September 2026 semester · Group 7

During semester breaks and public holidays, thousands of UTP students leave campus within a few days. Because many students book late, some don't show up and some never book, transport planners only know the final passenger numbers close to departure. ShareWay:

1. **Predicts final demand early** from the bookings made so far, while reservations are still open.
2. **Recommends vehicles** for each route and date: buses, a standby bus, a van, or cancel.
3. **Matches carpools** for students a bus or van can't serve (off-route destination, cancelled trip, or full vehicle).
4. **Estimates CO₂ and cost saved** compared with solo car or e-hailing trips.

Supports SDG 9 (Industry, Innovation & Infrastructure), SDG 11 (Sustainable Cities) and SDG 13 (Climate Action).

> ⚠️ **Prototype only.** Booking history is **simulated** from our student survey. Operator settings (fleet size, thresholds) are **team assumptions**. Outputs are estimates, not guarantees.

## How it works

```
Survey (Microsoft Forms)
        │  analyze_survey.py
        ▼
config.py ──► simulate.py ──► data/simulated/bookings.csv
                                        │  train.py
                                        ▼
  bookings so far ──► predict_final() ──► recommend() ──► buses / van / cancel
                                                  │
                    students not served ──► match() ──► carpool pairs
                                                  │
                                  co2_saved() ──► CO₂ and cost saved
                                                  │
                                           app.py (Streamlit)
```

| Step | File                | What it does                                                           |
| ---- | ------------------- | ---------------------------------------------------------------------- |
| 0    | `analyze_survey.py` | Turns survey responses into the `# SURVEY` values in `config.py`       |
| 1    | `simulate.py`       | Generates past booking data for every break, route and departure day   |
| 2    | `train.py`          | Regression model: bookings so far → final passengers                   |
| 3    | `decide.py`         | Vehicle rules based on predicted demand                                |
| 4    | `carpool.py`        | Matches passengers with student drivers (time difference, then detour) |
| —    | `emissions.py`      | Distances, CO₂ and cost saved                                          |
| —    | `app.py`            | Dashboard for operators and students                                   |

## Setup

Requires Python 3.10 or newer.

```bash
git clone https://github.com/Jessy123123/Group-7_ShareWay-UTP.git
cd Group-7_ShareWay-UTP
python -m venv .venv
```

Activate the environment:

- **Windows:** `.venv\Scripts\activate`
- **macOS/Linux:** `source .venv/bin/activate`

```bash
pip install -r requirements.txt
```

## Running

Run every command from the **repo root**.

```bash
python src/analyze_survey.py     # needs data/raw/survey.xlsx
python src/simulate.py           # writes data/simulated/bookings.csv
python src/train.py              # trains and saves the demand model
python src/scenarios.py          # runs the demo scenarios end to end
streamlit run app.py             # opens the dashboard
```

## Data and ethics

- Survey participation was voluntary, and no names, contact details or exact addresses were collected.
- Raw survey exports stay in `data/raw/`, which is excluded from Git.
- All booking history is **simulated** and labelled as such. Operator settings are **assumptions**.
- Predictions are estimates to support planning, not guaranteed numbers.
